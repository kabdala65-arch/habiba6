# موقع حبيبة ♥

موقع رومانسي عربي مبني بـ React + Vite + Framer Motion، مخصص لعيد ميلاد حبيبة بتاريخ **27 / 7 / 2026**.

## كلمة المرور

`Habouba`

## التشغيل

```bash
npm install
npm run dev
```

## إضافة الصور الست

ضعي الصور داخل `public/images/` بالأسماء التالية:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `photo6.jpg`

المعرض مجهز بست خانات فقط، وكل صورة تفتح في نافذة عرض كبيرة عند الضغط عليها.

## إضافة الأغنية

ضعي ملف الأغنية داخل `public/music/` باسم:

`our-song.mp3`

بعد كتابة كلمة المرور `Habouba` سيحاول الموقع تشغيل الأغنية تلقائيًا. لو المتصفح منع التشغيل التلقائي، اضغطي زر التشغيل الموجود أسفل الصفحة.

## إضافة الفيديو

ضعي ملف الفيديو داخل `public/video/` باسم:

`our-video.mp4`

سيظهر الفيديو في قسم **فيديو لحبيبة** مع أزرار التشغيل والتحكم. لا توجد رسالة صوتية منفصلة.

## ملاحظات التخصيص

- تمت إضافة قسم الفيديو مع الإبقاء على مشغل الأغنية، ومن دون رسالة صوتية منفصلة.
- العداد مضبوط على تاريخ عيد ميلاد حبيبة: `2026-07-27`.
- إذا كان التاريخ قد مرّ، يعرض العداد أصفارًا ورسالة تهنئة بدلًا من قيم سالبة.

## البناء للنشر

```bash
npm run build
```
